## 一、入门概念笔记

### 1. 人工智能、机器学习与深度学习之间有什么关系？

三者是**逐层包含**的关系：

- **人工智能（AI）** 是最外层的总称，指让机器表现出“智能”的一切技术，包括搜索算法、专家系统、逻辑推理、机器学习等。
- **机器学习（ML）** 是 AI 的一个子集：不靠人一条条写规则，而是让程序**从数据中自动学习规律**，再用学到的规律做预测。典型例子：垃圾邮件分类、房价预测。
- **深度学习（DL）** 是机器学习的一个子集：用**多层神经网络**（尤其是很深的网络）自动从数据中学习特征表示。它在图像、语音、自然语言处理上取得了突破。

一句话概括：深度学习 ⊂ 机器学习 ⊂ 人工智能。

### 2. 监督学习和无监督学习有什么区别？请各举一个例子。

区别在于**训练数据是否带有标签（正确答案）**：

- **监督学习**：训练数据是 `(输入, 标签)` 配对，模型学习从输入到标签的映射。例如：输入一封邮件的内容，标签是“垃圾/非垃圾”，训练一个**垃圾邮件分类器**；又比如根据房屋面积、地段等特征预测**房价**。
- **无监督学习**：数据只有输入、没有标签，模型自己去发现数据内在的结构。例如：把网购用户按行为**聚类**成不同群体（聚类）；用 PCA 对高维数据**降维**。

### 3. 数据、特征和标签分别是什么？训练集、验证集和测试集各有什么用途？

- **数据（data）**：收集到的原始样本整体。
- **特征（feature）**：喂给模型的输入变量。例如预测房价时，面积、楼层、地段就是特征。
- **标签（label）**：我们希望模型预测的目标值。例如那套房子的真实成交价。

数据集通常划分为三份：

| 集合 | 用途 | 是否参与训练 |
|------|------|--------------|
| 训练集 | 用来**拟合模型参数**（权重、偏置） | 是 |
| 验证集 | 用来**调超参数、选模型、监控过拟合** | 否 |
| 测试集 | 最后**评估泛化能力**，只用一次 | 否 |

关键原则：验证集和测试集都不能参与训练，否则会造成**数据泄漏**，评估结果会虚高。

### 4. batch size 是什么？有什么影响？

**batch size** 指一次前向+反向传播中，模型一次吃进多少条样本，再据此更新一次参数。

影响：

- **梯度估计的稳定性**：batch 越大，用一批样本平均出来的梯度越稳定，训练曲线越平滑。
- **显存/内存占用**：batch 越大占显存越多。
- **收敛速度与时间**：大 batch 能更好利用 GPU 并行，单步慢但每步“有效信息”多；小 batch 单步快但整体可能要更多步。
- **泛化**：小 batch 的梯度带噪声，有时反而能帮助跳出局部极小，泛化更好；大 batch 有时容易收敛到尖锐的极小点。

### 5. 什么是模型和模型参数？

- **模型**：一个带可调参数的函数（映射），它把输入特征变换成预测输出，例如 `y = Wx + b` 或更深的神经网络。
- **模型参数**：模型内部需要从数据中学习的具体数值，主要是**权重 W 和偏置 b**。训练的过程就是不断调整这些参数，使损失函数尽可能小。

### 6. 神经网络由哪些基本部分组成？什么是激活函数？为什么要激活函数？请介绍几种常见的激活函数。

基本组成：

- **输入层**：接收特征。
- **隐藏层**：每一层先做**线性变换**（`Wx + b`），再过一个**激活函数**。
- **输出层**：给出最终预测。
- **损失函数**：衡量预测与真实标签的差距。
- **优化器**：根据梯度更新参数。

**激活函数**是对线性变换结果做的一个**非线性**变换。如果不用它，无论堆多少层，整体都等价于一层线性变换，网络表达能力非常有限；引入非线性后，神经网络才能拟合任意复杂的函数。

常见激活函数：

- **Sigmoid**：把值压到 (0,1)，常用于二分类输出；缺点是梯度饱和。
- **Tanh**：压到 (-1,1)，以 0 为中心，仍会饱和。
- **ReLU**：`max(0, x)`，计算简单、缓解梯度消失，是隐藏层最常用的选择；缺点是 x<0 时梯度为 0。
- **Leaky ReLU**：x<0 时给一个小斜率，缓解“死神经元”。
- **Softmax**：把一组值变成概率分布（和为 1），常用于多分类输出。
- **GELU**：Transformer 中常用。

### 7. 矩阵如何求导？

当损失是标量 L、而要对矩阵求导时，结果是**与矩阵同形状**的矩阵，每个元素是对应位置的偏导数：

`dL/dW` 的第 (i,j) 个元素是 `∂L/∂W_ij`。

几个常用结论（约定分母布局，标量对向量/矩阵）：

- 对 `y = Wx`：`∂y/∂W = x`（外层），`∂y/∂x = Wᵀ`。
- 对 `L = ||Wx - t||²`，由链式法则：`∂L/∂W = 2(Wx - t) xᵀ`。
- 链式法则：若 `L = g(f(W))`，则 `∂L/∂W = ∂L/∂f · ∂f/∂W`，矩阵形式里要注意转置和形状对齐。

**检验小技巧**：梯度矩阵的形状必须与 W 相同；可以用“数值梯度”（给 W 某个元素加一个小扰动看 L 变化）来验证解析梯度是否正确。

### 8. 怎么用矩阵乘法表示神经网络的全连接层前向传播过程？

单个样本时，全连接层就是一次仿射变换：

`z = W x + b`

其中 x 是输入向量，W 是权重矩阵（行数=输出神经元数，列数=输入特征数），b 是偏置向量。

一批样本时，把所有样本按行堆成一个矩阵 X（每行一个样本），前向传播写成：

`Z = X Wᵀ + b`

即“输入矩阵 × 权重矩阵转置”。这样一次矩阵乘法就同时算完了整批样本的输出，既简洁又能在 GPU 上高效并行。

### 9. 前向传播与反向传播分别在做什么？损失函数、梯度和学习率在训练过程中扮演什么角色？

- **前向传播**：把输入沿着网络从前往后算一遍，得到预测值，并据此算出**损失**（预测与真实答案的差距）。
- **反向传播**：用链式法则，把损失对每个参数的**梯度**从后往前传回去，告诉每个参数“往哪个方向调、调多大，损失才会下降”。
- **损失函数**：量化“当前模型有多差”，是优化的目标。
- **梯度**：损失函数增长最快的方向；更新参数时沿**负梯度**方向走，损失就会下降。
- **学习率**：每次沿负梯度方向迈多大一步；太大容易震荡发散，太小则收敛太慢。

### 10. 优化器是什么？有哪些？

**优化器**是用梯度来更新参数的算法。最简单的是 SGD：`θ ← θ - lr · g`。之后出现很多改进，主要为了加速收敛、减小震荡：

- **SGD / Momentum（带动量）**：动量项让更新更平滑。
- **AdaGrad**：对频繁更新的参数减小学习率。
- **RMSProp**：用梯度平方的移动平均做自适应缩放。
- **Adam**：结合动量与自适应学习率，是目前最常用的默认选择。
- **AdamW**：在 Adam 基础上把权重衰减和自适应学习率解耦，训练大模型更常用。

### 11. 什么是过拟合、欠拟合、正则化？

- **过拟合（overfitting）**：模型把训练数据（包括噪声）记得太死，训练集损失很小、但验证/测试集表现差。相当于“死记硬背，不会举一反三”。
- **欠拟合（underfitting）**：模型太简单，连训练集都学不好，训练和测试损失都高。相当于“没学会”。
- **正则化（regularization）**：用来抑制过拟合的一组技术，例如 **L1/L2 正则**（惩罚过大的权重）、**Dropout**（训练时随机丢神经元）、**数据增强**、**早停（early stopping）**、**减小模型容量** 等。

### 环境相关问题回答

**1. 为什么不同项目最好使用不同的 Python 虚拟环境？**

不同项目依赖的库和版本往往不一样（例如 A 项目要 PyTorch 2.x，B 项目要 1.x；或两个项目要不同版本的 numpy）。如果都装进同一个环境，会互相覆盖、产生依赖冲突，还很难复现。每个项目一个虚拟环境，可以把依赖**隔离**开来，互不干扰，也便于记录和复现（配合 requirements 文件）。

**2. CPU 和 GPU 各自擅长什么？训练神经网络为什么经常使用 GPU？**

- **CPU**：核心少但单个核心强，擅长**串行、逻辑复杂、低延迟**的任务（操作系统调度、分支多的代码）。
- **GPU**：核心极多（几千个），擅长**大规模并行、同一种运算重复执行**的任务。

神经网络训练的核心是大量的**矩阵乘法**，而矩阵乘法天然可以拆成成千上万个独立的乘加运算并行执行，正好契合 GPU 的并行架构，所以训练能比 CPU 快几十甚至上百倍。

**3. CUDA 是什么？它、显卡驱动与 PyTorch 之间大致是什么关系？**

- **CUDA**：NVIDIA 推出的**并行计算平台和编程接口**，让开发者能用 GPU 做通用计算，而不只是渲染图形。
- **显卡驱动**：操作系统与显卡硬件之间的“翻译官”，负责让系统能调用 GPU；CUDA 程序运行也需要相应版本的驱动支持。
- **PyTorch**：调用 CUDA 提供的接口，把张量运算和神经网络算子放到 GPU 上执行。

大致关系：**PyTorch（上层框架）→ CUDA（并行计算接口/工具）→ 显卡驱动（操作系统与硬件的桥）→ GPU 硬件**。
