## 实践 1：卷积核

### 数字图片如何表示

- **像素**：图片被离散成的最小单元，每个像素存储一个或多个数值。
- **RGB**：彩色图用红、绿、蓝三个通道叠加表示颜色，每个通道一个 0–255 的数值。
- **灰度图 vs 彩色图**：灰度图只有一个通道（亮度），彩色图有 R/G/B 三个通道。

用 Pillow 把测试图转成 NumPy 数组后：

```text
shape = (256, 256, 3)   # H, W, C
dtype = uint8
min = 0, max = 255
像素 (100,100) 的 RGB = [255, 255, 255]
```

`shape=(H,W,C)` 说明每个维度分别表示高、宽、通道，数值 0–255 表示颜色强度。**HWC**（NumPy/Pillow 常用）与 **CHW**（PyTorch 常用）只是维度排列顺序不同，送入 PyTorch 前常用 `transpose((2,0,1))` 转换。

### 二维卷积是什么

**卷积核**是一个小的权重矩阵（如 3×3）。它像一扇“滑动窗口”，从图片左上角开始，按 stride 逐格滑动；每到一个位置，把窗口内像素与卷积核对应位置**相乘再求和**，得到输出图对应位置的一个值。整张图滑完就得到输出特征图。

`convolution.py` 里只用了 NumPy 的双重循环实现，没有调用任何现成卷积函数。

### 四种卷积核的效果与解释

对比图见 `figs/conv_results.png`。

- **均值模糊（3×3 全 1/9）**：每个输出像素是周围 3×3 邻域的**平均**，把突变抹平，所以变模糊。
- **高斯模糊（5×5 高斯核）**：同样是加权平均，但**中心权重更大、越远越小**，比均值模糊更自然、保留更多主体轮廓。
- **锐化 `[[0,-1,0],[-1,5,-1],[0,-1,0]]`**：相当于“原图 × 1 + (原图 - 邻域均值)”，把每个像素和周围的反差**放大**，边缘因此更明显。
- **Sobel-X / Sobel-Y**：近似水平/垂直方向的**梯度**。边缘处灰度变化剧烈、梯度大，所以能定位边缘；把两个方向结果按 `sqrt(gx²+gy²)` 合成，就得到各方向的边缘图。

### valid 与 same padding

输出尺寸公式：`out = (in - k + 2p) / stride + 1`。

对 256×256 输入、3×3 核、stride=1：

```text
valid（padding=0）输出：(254, 254)   # out = in - k + 1
same（padding=1）输出：(256, 256)    # padding=(k-1)/2 时 out = in
```

不填充时边缘像素参与卷积的次数少，输出会变小；适当填充能保持尺寸，并让边缘信息被完整利用。卷积后结果可能超出 [0,255]（如锐化出现负值、Sobel 很大），保存前要 `clip` 到 [0,255]。

## 实践 2：训练猫狗分类器

### 数据读取与预处理

`ImgDataset` 完成：读图 →（训练时）随机水平翻转/随机裁剪/颜色扰动 → resize 到 64×64 → 转 CHW → 归一化到 [0,1]，再用 DataLoader 组成 batch。增强前后的样本可在代码里取消注释随机展示来检查是否拉伸、裁错或颜色异常。

### CNN 结构与各层形状

3 个 `Conv-BN-ReLU-MaxPool` block + 分类头。以 3×64×64 输入为例，各层张量形状变化：

```text
conv0: (1,16,64,64)  -> pool: (1,16,32,32)
conv1: (1,32,32,32)  -> pool: (1,32,16,16)
conv2: (1,64,16,16)  -> pool: (1,64,8,8)
flatten -> fc(128) -> fc(2)
```

可以看到：**宽高逐层减半、通道数逐层增多**。结构示意图见 `figs/cnn_structure.png`，特征图可视化见 `figs/feature_maps.png`。

### 训练、曲线与错误分析

训练/验证/测试按类别分层划分，绘制 loss/accuracy 曲线（`figs/cnn_curves.png`），保存最优模型 `catdog.pt`，并输出混淆矩阵。`predict.py` 用保存的模型对单张图片做推理，输出“猫/狗”与概率，并保存预处理后的图片。

### 真实数据训练结果

在 Zenodo 的 `cats_dogs_light` 数据集（[record 5226945](https://zenodo.org/record/5226945)）上训练了 20 个 epoch。数据为 64×64 的小图，共 1000 张训练图（cat 455、dog 545），按类别分层划分为 train 702 / val 149 / test 149。

```text
验证集最佳 acc = 0.7181（epoch 7）
测试集：acc = 0.6779  loss = 0.5843
混淆矩阵（行=真实，列=预测，0=猫 1=狗）：
[[56 12]      # 56 只猫判对，12 只猫误判成狗
 [36 45]]     # 45 只狗判对，36 只狗误判成猫
```

模型参数量 548,482，`catdog.pt` 约 2.2MB。曲线见 `figs/cnn_curves.png`：训练准确率最终约 0.78、验证约 0.71，存在一定过拟合，符合“小数据 + 数据增强”的预期。可尝试增加 epoch、调大 Dropout、换更强的增强或迁移学习进一步提升。

> 注：此前无真实数据时用 `--demo` 的合成二分类图像验证过整条流水线；现在已补充上述真实数据训练，`catdog.pt` 与相关图片均为真实数据产物。复现命令：`python cnn_train.py --data <解压后的 train 目录> --epochs 20`。

### 数据增强对照实验

代码里 `ImgDataset(augment=True/False)` 一键切换。建议对照：

- **无增强**：训练 acc 可能很高但容易过拟合，泛化差；
- **随机水平翻转**：对猫狗这类左右对称目标合理；
- **随机裁剪**：提供平移/尺度变化，提升鲁棒性；
- **颜色扰动**：增强对光照变化的鲁棒性，但对“颜色是关键线索”的任务要谨慎（可能破坏标签）。

翻转、裁剪、颜色扰动都只在**训练集**使用；验证集和测试集保持原始分布，才能公平评估。

## 趁热打铁

**1. 卷积层为什么比巨大全连接层更适合图片？**

卷积有**局部连接**和**参数共享**两个特性：一个卷积核只连接一个小邻域、且整张图复用同一组权重。相比全连接，参数量大幅减少、不易过拟合，还能自然利用图片的**空间结构**（相邻像素相关性更强）。用全连接处理图片不仅参数爆炸，还会丢失空间位置信息。

**2. 输入通道和输出通道分别表示什么？与卷积核数量关系？**

输入通道 = 该层输入特征图的通道数（如 RGB 是 3）；输出通道 = 该层卷积核的**个数**，每个卷积核扫一遍输入得到一张特征图，所以输出通道数等于卷积核数量。

**3. padding、stride、pooling 怎样改变尺寸？**

统一公式：`out = (in - k + 2p)/stride + 1`。卷积里 p 是 padding；pooling 类似，`k` 为池化窗口大小、stride 为池化步长（2×2、stride=2 时尺寸减半）。结合上面网络：64 输入、3×3、p=1 卷积后仍是 64，2×2/stride=2 池化后变 32。

**4. 为什么网络越深，宽高变小、通道变多？**

池化/步长卷积让**空间尺寸**逐步缩小（增大感受野、降低计算量）；同时用更多卷积核提取更多**语义特征**，所以通道数变多。整体是“从低层空间细节到高层语义”的抽象过程。

**5. 你选择了什么激活函数和损失函数？为什么适合二分类？**

激活用 **ReLU**（稳定、计算快），损失用 **CrossEntropyLoss**（二分类输出 2 个神经元）。它内部是 softmax + 交叉熵，能把输出解释为两类概率，训练稳定，是二分类标准做法。

**6. 为什么训练集的随机增强不能原样用在验证/测试集？**

增强的目的是让模型见过更多“变形”从而更强壮，但它会改变数据分布。验证/测试集必须保持**干净、固定**的分布，才能公平衡量模型真实泛化能力；对它们做随机增强会让评估结果不稳定、不可比。

## 拓展（选做，简要笔记）

- **AlexNet / VGG / ResNet**：AlexNet 用大卷积核（11×11、5×5）+ ReLU+Dropout 首次展示深度 CNN 威力；VGG 统一用 3×3 小卷积核堆叠加深（16/19 层）；ResNet 引入**残差连接**解决深层退化，可以堆到上百层。三者体现了“卷积核变小、网络变深、加入捷径”的演进。
- **BasicBlock vs Bottleneck**：ResNet-18/34 用两个 3×3 卷积的 BasicBlock；ResNet-50+ 用 1×1→3×3→1×1 的 Bottleneck，先降维再升维，参数量更少，适合更深网络。小任务上 Bottleneck 不一定更优，需要实验对比。
- **特征图 L2 范数分析**：对 `(b,c,h,w)` 沿 h、w 求 L2 范数得到 `(b,c)`，可比较浅层（多关注边缘/纹理，通道响应分散）与深层（通道响应更“专一”/稀疏）的差异。
- **手写经典网络**：可用 PyTorch 手写一个简化 VGG/ResNet（不直接调 `torchvision.models`），作为结构理解练习。
