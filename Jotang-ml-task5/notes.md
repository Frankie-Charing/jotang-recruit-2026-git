# Task 5（拓展题）：VLM 从这开始 —— CLIP 阅读笔记

> 论文：Learning Transferable Visual Models From Natural Language Supervision（OpenAI, 2021）

## 一、任务 1：阅读 CLIP

### 1. 传统图像分类模型需要怎样的数据？CLIP 为什么用互联网“图片—文字”对？

传统图像分类需要**大量人工标注**的 `(图片, 类别标签)` 数据：每张图都要人标出它属于哪个固定类别，增加新类别还要重新标注、重新训练。CLIP 改用互联网上天然存在的大规模 **“图片—文字”对**（例如网页里的图和它的说明文字）作为监督信号，省去了昂贵的人工标注，并且把监督信号从“离散标签”升级成“自由文本”，可扩展性大大增强。

### 2. CLIP 由哪两个编码器组成？图片和文字经过编码器后分别变成什么？

由**图像编码器**（ResNet 或 ViT）和**文本编码器**（Transformer）组成。图片经过图像编码器变成一个向量 `I`，文字经过文本编码器变成一个向量 `T`，两者被映射到**同一个联合嵌入空间**，可以直接比较相似度。

### 3. 什么是图文对齐？为什么语义匹配的向量应该更接近？

图文对齐就是让“含义相同”的图片向量与文本向量在联合空间里**距离近（相似度高）**，含义不同的则距离远。因为只有这样才能用一个统一的度量（余弦相似度）判断“这张图是不是这句话描述的东西”，从而支撑后续的检索与 zero-shot 分类。

### 4. 结合 Figure 1，说明 N×N 配对、正负样本

一个 batch 里有 N 张图片和 N 段文字，两两组合可以构成一个 **N×N 的相似度矩阵**：对角线上的 N 对 `(图片 i, 文字 i)` 是**正样本**（原本就是配对的），其余 `N²-N` 对是**负样本**（图与文不对应）。

### 5. CLIP 的训练目标是什么？

用对比学习：**让正样本对的相似度尽量高，负样本对的相似度尽量低**。具体是 InfoNCE 损失，对相似度矩阵的每一行（图片→文字方向）和每一列（文字→图片方向）都做 softmax + 交叉熵，把正确配对当成“分类目标”。

### 6. 什么是 zero-shot classification？为什么只给类别名就行？

把每个候选类别写成一句话（例如 “a photo of a cat”），用文本编码器得到类别向量；再拿图片向量和所有类别向量算相似度，取最相似的那个作为预测。因为图片和文字在同一个空间，**不需要针对新类别做任何训练**，直接“零样本”分类。

### 7. 什么是 prompt engineering？dog 与 "a photo of a dog" 有区别吗？

就是设计**给文本编码器的类别描述模板**。CLIP 训练时文字是完整的句子，而测试时如果只输入一个孤立的词 `dog`，会与训练分布不一致，效果可能变差；改成 `"a photo of a dog"` 更接近训练时的自然语言风格，通常更准。原文还对 80 种 prompt 模板做了集成。

### 8. CLIP 的局限与偏见？

局限：零样本准确率仍低于有监督的专用模型；对细粒度、抽象、计数类任务较弱；对数据分布外（OOD）的泛化也不是万能的。

偏见/错误关联：互联网图文数据本身带有社会偏见与统计捷径——例如某些职业总与特定性别/肤色同时出现，CLIP 可能学到这些错误关联。这提示如今大模型训练的一个核心思想：**模型学到的不是“事实”，而是数据里的统计规律；数据质量与多样性直接决定模型的行为与偏见**。

## 二、趁热打铁

### 1. 为什么图片特征与文本特征可以计算相似度？两个编码器输出需满足什么条件？

因为 CLIP 把两个编码器的输出**投影到了同一个向量空间**（维度一致），且训练目标是让语义相关的图文向量靠近。只要两个编码器输出**同维度、可比**的向量，就能算点积/余弦相似度。

### 2. 为什么要先 L2 归一化？归一化后的点积与余弦相似度什么关系？

把向量除以其 L2 范数，长度变成 1，只保留方向。归一化后两个向量的**点积就等于余弦相似度**，消除了模长对相似度的干扰，让相似度稳定在 [-1, 1]。

### 3. 为什么 CLIP 训练损失从两个方向计算？

因为相似度矩阵既可以从“图片找文字”也可以从“文字找图片”两个方向看。只做一个方向，某些负样本可能得不到足够的梯度、学习不充分；双向损失让图片和文本两个编码器都被同等约束，学到的空间更一致。

### 4. zero-shot 真的意味着模型从未见过相似内容吗？与“不对当前任务训练”有何区别？

不一定。zero-shot 只表示**没有在当前任务的数据上微调**，但模型在海量预训练里很可能见过相似的概念（例如见过很多猫的图片和 “cat” 这个词）。它强调的是“不针对当前任务重新训练”，而不是“从未接触相关概念”。

### 5. 可学习温度系数对 softmax 分布与确信度的影响？

温度 τ 会乘在相似度上再做 softmax。τ **变大**，logits 被压缩，softmax 分布更**平滑**、模型更“不确定”；τ **变小**，logits 被放大，分布更**尖锐**、模型更“确信”。CLIP 把它设为可学习参数，让模型自己调合适的确信度。

### 6. 若“雪地”常与“北极熊”同时出现，模型可能学到什么捷径？有什么影响？

模型可能学到“雪地 ↔ 北极熊”的**虚假相关**：看到雪地背景就容易预测北极熊，或反过来。这种统计捷径在真实场景会带来错误——比如把雪地里的狗也当成北极熊，导致模型被数据偏见误导。

## 三、探究 CLIP 的应用场景

图文检索、零样本图像分类、图像生成（与扩散模型结合，如 DALL·E 系列用它做文本—图像对齐）、内容审核、跨模态搜索等。
